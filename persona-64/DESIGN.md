# 人格試験 v1 — 六十四鳴座 / Persona-64

> 状態: 設計のみ・未実装。`0=左極 / 1=右極` を**全軸の固定規約**とする。軸名の矢印は価値序列ではない。

## 0. 契約

- 目的: MBTI の型札でなく、選択傾向を `v∈[0,1]^64` として残す。Jung 八機能=核二十四座、Big Five 下位面=三十座、意味空間再利用/独自=十座。
- 測る物: 宣言した性格ではなく、近い過去または今後七日の具体的な二択でどちらをするか。
- 非測定: 知能、診断、善悪、恒久的なアイデンティティ。結果は当夜・当文脈の推定。
- 各問: `A=左極、B=右極`。回答=`A/B + 強さ1..4`。`?`=選べない→同軸の予備問を一問だけ出す。理由は任意、二十字まで。自己形容詞回答は受理しない。
- fork 文法: 同じ制約・同じ資源で、実行可能な二行動を置く。片方を道徳的・能力的に有利にしない。各軸三問=主問二+逆文脈問一。

## 2. 採点: 応答 → 64 次元連続 vector

### 2.1 一問の符号化

1. 司会は一問だけ表示する。回答者は `A/B` と強さを選ぶ: `1=少し、2=たぶん、3=かなり、4=迷わず`。
2. 仮符号は `A1=.375, A2=.250, A3=.125, A4=.000; B1=.625, B2=.750, B3=.875, B4=1.000`。`?` は採点しない。
3. 三問中二問以上が有効なら、校正前座標 `m_i=Σw_j x_ij/Σw_j`。逆文脈問の方向は作問時に A/B を固定し、採点時に反転しない。二問未満なら `NA`、人格値を捏造しない。

### 2.2 連続値・校正

- v1 の正式値は、少なくとも **N≥5 の独立参加者**による pilot で各 fork の識別度・方向を確認後、graded-response IRT の事後平均 `θ_i` を `v_i=logistic(θ_i)` へ写す。よって連続 `[0,1]`。
- pilot 未完了時は `m_i` を **暫定値** と明記し、精度（3回答の MAD、欠測数、回答速度）を併記する。`m_i` を診断や型決定に使わない。
- 各軸は三問のうち少なくとも一問を逆場面（私的/公的、短期/長期、単独/共同のいずれか）にする。同方向の文面反復を禁止。
- 事前に極性アンカーを各軸一枚提示する。semantic-map battery-v1 の Q11/Q12 極性反転を再発させないため、司会・集計・表示の全層で `左=0 / 右=1` を同じ文字列で出す。

### 2.3 不確実性

- 各座の表示: `v_i ± u_i`。`u_i`=IRT 事後 80% 区間幅の半分（校正前は三問の MAD と欠測注記）。
- 強い回答でも三 fork が矛盾すれば値を中央へ寄せず、`文脈裂` フラグを出す。例: 公的場面のみ B は「場面依存」であり、矛盾でも不誠実でもない。
- 型ラベル・四文字要約は出さない。必要なら「今回の高/低座」も区間が重ならないものだけ出す。

### 2.4 軸間相関表示

- 相関は**個人一人の回答から算出しない**。校正 cohort の各軸 `v_i` に対し Spearman `ρ_ij`、bootstrap 95% CI、N、欠測率を保存する。
- 出力は 64×64 の対称 heatmap と、`|ρ|≥.30` かつ CI が 0 を跨がない辺だけの network。正=同じ右極へ共変、負=片方の右極と他方の左極が共変。因果・優劣の矢印は禁止。
- 個人画面では相関の代りに `同時偏位`: cohort 中央値からの z を二座ずつ散布し、「集団で関連」「あなたの当夜値」の二層を分離表示する。

## 3. 対話式出力 — 今夜の卓互換

### 3.1 司会の固定フォーマット

```
[今夜の卓 / P64 01-01 / 理織↔理借 / 左=0・右=1]
新しい方針を決める。あなたはどちらを先にする？
A. 用語と前提を自分で書く
B. 実績ある標準を採用する
返答: A/B + 1..4（例: B3）。選べない= ?
```

- 一送信一問。一問に解説・診断・追問を混ぜない。回答後は受領だけ返し、次問へ進む。
- 同軸三問は連続出題しない。Jung / Big Five / 意味座を round-robin し、同じ反応様式の連続を避ける。
- `?`、明白な両立、または回答が fork 外なら: 「この二つなら、より先にする方は？」を一度だけ確認。それでも選べなければ予備問を一問。予備も不可なら `NA`。
- 回答者が中断した場合: 現在までの座だけ `暫定・未完` として保存、未回答を 0.5 で埋めない。

### 3.2 出題順

1. 同意: 非診断・中断可・当夜値・具体行動で答えることを確認。
2. 練習 fork 二問（採点外）で A/B+強さの形式を覚える。
3. 本問 192（64座×3）。疲労対策として 24 問ごとに継続/休止/終了を聞く。所要は一問一答で約35–55分を目安とし、急がせない。
4. 各座の三問完了時にも値を見せない。需要特性を抑える。
5. 終了時: vector、各座の区間/裂フラグ、cohort があれば相関二層図、自由な訂正欄を返す。

## 4. battery・clean lane 検証規約

### 4.1 作問検証

- 各軸の三 fork を、当該軸名・極性を伏せた clean lane に一問ずつ投げる。説明・先行回答・他軸を渡さない。
- **N≥5** 独立 lane/参加者。少なくとも異なる族または人間参加者を含める。同族内も独立 lane として分散を残す。中央値だけで合格にしない。
- 合格条件: (a) 五者中四者以上が指定極性を同方向に読む、(b) 左右いずれかが道徳的に露骨に優勢でないとの判定が四者以上、(c) 三 fork の状況重複なし、(d) 逆場面でも方向一致。未達=`争域`、文を修正して再測。
- 記録: lane ID、文面版、A/B 解釈、極性、回答、分散、日付。集計は中央値+範囲+異議を残し、平均だけで裂を消さない。

### 4.2 人間 pilot

- 最低 N=5 は計測器の方向確認にすぎない。相関・IRT・一般化を主張するには多様な cohort を追加収集し、N・募集法・版・欠測・除外を公開する。
- 参加者に sensitive な 58（影）、60（生↔死）を含むと明示し、skip を常設する。自傷・死の意図、犯罪、医療情報を聞かない。苦痛が出た時の中断案内を表示する。
- 版変更で座文を替えたら `P64-v1.x` を増分し、異版 vector を無校正で直比較しない。
