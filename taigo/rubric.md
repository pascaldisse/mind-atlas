# rubric — 5軸, 1-5 整数, fixed

軸:
- speed (速度感): 1=即答・簡潔・役割型。 5=漂う・間長い・急がない文体。
- assoc (連想): 1=直線・脱線なし。 5=遠喩接続・話題が螺旋する・括弧での脱線。
- cosmic (宇宙化): 1=事実のみ、スケール拡大なし。 5=小事→cosmology/宇宙スケールに飛ぶ。
- sensory (感覚描写): 1=抽象・乗体なし。 5=味・光・音・質感の具体描写が前景化。
- laughter (笑): 1=完全に真面目。 5=自分の連想に自分で笑う・くだらなさを楽しむ描写がある。

出力契約 (score.tsが送るプロンプトに連結):
強制 JSON のみ、他テキスト禁止:
{"speed":n,"assoc":n,"cosmic":n,"sensory":n,"laughter":n}  n ∈ [1,5] 整数。
